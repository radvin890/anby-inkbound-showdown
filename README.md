# Anby: Inkbound Showdown

Build a polished, playable 2D side-scrolling run-and-gun boss-fight browser game inspired by the hand-drawn 1930s rubber-hose cartoon look of classic Cuphead, but use original assets and original enemy designs (do not copy Cuphead characters, art, music, or levels). The playable hero is Anby Demara from Zenless Zone Zero, portrayed recognizably but in a charming simplified hand-drawn cartoon style: short silver bob hair, dark headband, black outfit with white accents, and a short sword-like combat style. Keep the game lightweight and performant, playable in browser on desktop and mobile.

Make the game genuinely playable, not just a mockup: a start/menu screen, a horizontally scrolling battlefield, Anby can move left/right and jump, fire energy projectiles, dash/dodge, and fight at least one multi-phase original boss with readable telegraphs, varied attack patterns, health bars, hit feedback, victory/defeat states, restart button, and pause. Use canvas or a suitable lightweight 2D game approach with responsive scaling and keyboard controls (A/D or arrows move, Space jump, J shoot, K dash, Esc pause); add touch controls for mobile. Make combat feel responsive, include cooldowns and invulnerability frames, collision detection, particles, screen shake used sparingly, parallax background, layered scenery, hand-drawn ink outlines, warm paper grain, vintage muted palette, and jazzy-cartoon visual styling without using copyrighted Cuphead assets. The boss should be an original theatrical clockwork/teapot-like creature with distinct phases and clear telegraphs. Add a simple tutorial overlay and controls legend. Main UI language should be English, with a small Persian subtitle/tagline optionally. Use synthesized original sound effects via Web Audio if feasible; do not use copyrighted music. Ensure no placeholder buttons: every control works. Make the game accessible and fun, with a title such as 'ANBY: INKBOUND SHOWDOWN'. Build the game now and ensure preview works.
